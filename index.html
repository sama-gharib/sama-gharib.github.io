How ?

This website was made with Haskell! This Haskell code:

nesting 0 = ul $ li "I'm nested!"
        nesting n = ul $ li (show n ++ nesting (n-1))
        nesting 3

Produces this HTML:

<ul><li>3<ul><li>2<ul><li>1<ul><li>I'm
        nested!</li></ul></li></ul></li></ul></li></ul>

Which is formatted like so:

  • 3
    • 2
      • 1
        • I'm nested!

Is Haskell the best way to do web dev?

No. But functional programming definitely has something to bring to the table in UI programming. I tried Elm but this was a bit too much bloat for such a simple website. I would like to develop my own hobby web UI DSL at some point in the future.
